## 它解决什么

AIGC 的流程往往不止一步：文本编码 → 采样 → 放大 → 后处理 → 换脸/重绘。
ComfyUI 用节点图把这条链路显式画出来，**每一步都可替换、可缓存、可复现**，
并且工作流能存成 JSON 分享——这比"一堆滑块"的界面更适合工程化使用。

## 什么时候用它

- 要用 FLUX / SD3.5 / HunyuanVideo / Wan 这类新模型 → 它通常是最先有可用节点的地方。
- 想把流程固化下来（同一套工作流批量出图）→ 节点图 + API 模式正好。
- 想组合多个模型（生成 + 放大 + 局部重绘）→ 节点式天然支持。

## 上手难点

- **自定义节点的依赖地狱**是最常见的时间黑洞：不同节点要求不同版本的 torch / xformers。
  建议每个项目独立环境，别用一个环境装所有节点。
- 节点图复杂后可读性差，建议保存工作流 JSON 并写注释节点。
- GPL-3.0 许可，把它集成进闭源产品前先确认合规边界。
- 显存管理靠 `--lowvram` 之类的启动参数，不同模型的推荐值不一样。
