## 它解决什么

很多团队的算力不是一整排同型号的 NVIDIA 卡，而是混合着国产加速卡的老新旧机器。
赤兔定位于「生产级大模型推理引擎」，把多元算力适配当成第一特性：NVIDIA 从新旗舰到旧款，
以及昇腾、沐曦、海光、摩尔线程等国产芯片都有优化支持；同一套引擎可从纯 CPU 部署、
单 GPU 一直扩到集群。它的更新记录里能看到昇腾 910B 原生支持、FP4 在线转 FP8/BF16、
CPU+GPU 异构单卡跑 DeepSeek-R1 671B 这类里程碑。

v0.6.0 起提供 `chitu.run` 可执行文件，单文件即可拉起多节点、多实例、PD 分离等复杂部署。

## 什么时候用它

- 手上是国产卡或混合算力，通用引擎支持不到位时。
- 有一体机 / 私有化交付需求，需要长期稳定承载并发业务流量。
- 想把部署形态从单实例走到多节点 / PD 分离，而不换引擎。

## 上手难点

- 官方建议用 `chitu.run` 与 Releases 里的资产部署，环境与驱动组合要按开发手册对齐。
- 性能数据与硬件、软件版本、测试负载强相关，官方自己也提示要自测；多测几次会有波动。
- 团队在 README 里明确说无法保证及时处理所有问题，需要专业支持得走商业渠道。
